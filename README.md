# 🔒 PassGuard – Password Security Analyzer

A professional cybersecurity-themed **Password Security Analyzer** that runs 100% in the browser — no server, no backend, no data transmission.

## 🌐 Live Demo

> **GitHub Pages URL:** `https://<your-username>.github.io/<repo-name>/`

## ✨ Features

- **Real-time password analysis** — scores update as you type
- **Security score** (0–100) with visual strength meter
- **8 security checks**: length, uppercase, lowercase, numbers, special characters, repeated characters, common sequences, character variety
- **Smart recommendations** — tells you exactly what to fix
- **Strong Password Generator** — cryptographically-inspired, 20-character passwords
- **Copy to clipboard** button
- **Privacy-first** — your password never leaves your browser

## 🚀 How to Deploy on GitHub Pages (2 minutes)

1. Create a new repository on GitHub (e.g. `passguard`)
2. Upload the `index.html` file to the repository root
3. Go to **Settings → Pages**
4. Under **Source**, select `main` branch and `/ (root)` folder
5. Click **Save**
6. Your site will be live at `https://<your-username>.github.io/<repo-name>/`
